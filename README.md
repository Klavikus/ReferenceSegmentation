## Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Klavikus/ReferenceSegmentation/blob/master/ReferenceSegmentationDemo.ipynb)

1. Откройте ноутбук по кнопке.
2. Для SAM2 выберите **Среда выполнения → Сменить среду выполнения → GPU** (например, T4).
3. Выполните ячейку установки, затем ячейку запуска.
4. Откройте ссылку Gradio, появившуюся после запуска.

Ячейка установки использует нативные команды Colab `%shell`: показывает версию Python, текущий этап и вывод Git/pip прямо под ячейкой. Дождитесь сообщения **«Установка завершена»**; при ошибке следующий этап не запускается. Если Colab предлагает перезапустить сессию после установки пакетов, выполните перезапуск и снова запустите ячейку установки, затем ячейку интерфейса.

SAM2 включён по умолчанию. Для ручной разметки без GPU снимите флажок `use_sam2` в ячейке установки. При первом запросе SAM2 скачивает веса модели из Hugging Face; требуется интернет. Интерфейс доступен, пока работает сессия Colab.
